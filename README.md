# Desafios Python

Repositório criado para armazenar os desafios desenvolvidos durante meus estudos em Python.

O objetivo deste projeto é praticar lógica de programação, sintaxe da linguagem, resolução de problemas e organização de código, registrando minha evolução ao longo do curso.

---

##  Sobre o projeto

Este repositório reúne exercícios e desafios práticos feitos durante meu aprendizado em Python.  
Cada desafio foi desenvolvido com foco em reforçar conceitos fundamentais da linguagem e melhorar minha capacidade de resolver problemas por meio da programação.

A proposta é utilizar este espaço como um diário de evolução, onde cada arquivo representa uma etapa do meu desenvolvimento como programadora.

---

##  Objetivos

- Praticar lógica de programação;
- Aprender e reforçar a sintaxe do Python;
- Resolver desafios de forma organizada;
- Desenvolver raciocínio computacional;
- Criar uma base sólida para projetos futuros;
- Acompanhar minha evolução nos estudos.

---

##  Tecnologias utilizadas

- Python
- Git
- GitHub
- VS Code

---

##  Conteúdos praticados

Ao longo dos desafios, serão trabalhados conceitos como:

- Variáveis e tipos de dados;
- Entrada e saída de dados;
- Operadores aritméticos;
- Estruturas condicionais;
- Estruturas de repetição;
- Listas, tuplas e dicionários;
- Funções;
- Manipulação de strings;
- Tratamento de erros;
- Organização de código.
